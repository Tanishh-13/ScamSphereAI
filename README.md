# 🛡️ ScamSphere AI

### AI-Powered Fraud Campaign Intelligence Platform

ScamSphere AI helps detect scams, correlate complaints, uncover fraud campaigns, and provide actionable guidance using AI.

## 🚀 Features

* 📸 Screenshot Analysis using OCR
* 🎯 Scam & Entity Detection
* 🚨 Threat Score Generation
* 🕸️ Campaign Intelligence & Complaint Correlation
* 📊 Fraud Network Visualization
* 🤖 AI Cybercrime Copilot

## 🏗️ Workflow

```text
Screenshot / Complaint Text
            ↓
          OCR
            ↓
   Entity Extraction
            ↓
     Threat Scoring
            ↓
 Campaign Correlation
            ↓
   Fraud Network Graph
            ↓
    AI Cyber Copilot
```

## 🛠️ Tech Stack

* Python
* Streamlit
* Groq (Llama 3.3)
* EasyOCR
* Plotly
* NetworkX

```text
ScamSphereAI/
```

## ⚙️ Setup

```bash
pip install -r requirements.txt
```

Create a `.env` file:

```env
GROQ_API_KEY=your_api_key
```

Run:

```bash
streamlit run app.py
```
